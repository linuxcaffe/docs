# nb-web

**nb-web** is a browser-based interface for [nb](https://github.com/xwmx/nb) — the fast, plain-text, git-backed CLI notebook. It gives nb a full-featured web UI without replacing or bypassing the CLI: every note you create, edit, or sync through nb-web is a real file in your nb notebooks, fully accessible from the terminal.

---

## What you get

- **Browse and search** all your notebooks, folders, and notes in a split-pane list/preview layout
- **Edit** markdown notes inline, with a lightweight formatting toolbar
- **Add** notes, bookmarks, todos, and templates — with per-notebook defaults
- **Sync** via git: push, pull, and wire notebooks to GitHub remotes, all from the UI
- **Import** files (PDF, images, audio, video, docs, archives) and export notes in multiple formats
- **Tags**, full-text search, grep mode, and `--all` cross-notebook search
- **Keyboard navigation** throughout — arrow keys, `e` to edit, `d` to delete, `/` to search
- **Multiple notebooks** with per-notebook sort, template, and list-type defaults
- **Codeblocks**: live-rendered hledger and other code fences (requires companion tool)
- **Progressive Web App**: installable, works offline via service worker cache
- **Dark/light theme**, drag-to-resize panes, pinned notes, folder drill-down

## Quick start

1. Install nb — see [INSTALL](docs:12)
2. Clone nb-web and run `python app.py`
3. Open `http://localhost:5001` (or use the launch script for Epiphany PWA mode)
4. Your existing nb notebooks appear immediately in the scope selector
5. To sync with GitHub: open **Menu → Notebooks**, select a notebook, wire a remote

---

## Architecture in one paragraph

nb-web is a single Flask process (`app.py`) serving a single-page app (`index.html` + `main.js` + `nav.js`). The backend shells out to nb and git for all note operations — it keeps no database of its own. Notes live in `~/.nb/` as plain files, indexed by nb's `.index` files. A service worker caches the frontend for offline use; the cache key is the git commit hash, so deploying new code automatically invalidates old caches. Per-notebook preferences and app settings are stored in `~/.nb/nb-settings.json`.
